# План внедрения общего пула SOCKS5

> Параллельная работа по `superpowers:subagent-driven-development`: хранение и панель имеют собственные тесты. Интеграцию проверяем в общем worktree.

Цель — загружать каждый внешний SOCKS5 один раз, проверять его с каждого включённого и доступного IPv4 VDS и перенести действующие назначения в общий список.

Схема и маршрутизация описаны в `docs/specification.md`. Итоговая база ветки — `main` `3d75ec8`. Автоматический маршрут включается после успешной проверки, ручное отключение сохраняется. TCP-соединение использует закреплённый IPv4. При сбое маршрута отправки и реакции приостанавливаются. Тесты используют отдельную SQLite и фиктивный сетевой адаптер.
